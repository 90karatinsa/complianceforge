# Veritabanı Şemaları ve Migrasyonlar

Bu klasör, PostgreSQL 16 için Prisma/Knex tabanlı şema tanımlarını ve migrasyon betiklerini barındıracaktır. Temel tablolar şunları kapsayacaktır:

- `tenants`, `api_keys`, `projects`, `artifacts`, `scans`
- `sboms`, `licenses`, `vulns`
- `policies`, `webhooks`, `usage_metrics`

İlerleyen aşamalarda şemalar test fixture'ları ve seed verileriyle desteklenecektir.
