# Dokümantasyon

- [`openapi.yaml`](./openapi.yaml): /v1 REST yüzeyini kapsayan OpenAPI 3.1 şeması. Health, proje, tarama, SBOM, lisans, zafiyet, politika, webhook, rapor ve değişiklik uç noktaları için istek/yanıt şemalarını içerir.
- [`quickstart.md`](./quickstart.md): 5 dakikada ilk taramayı tamamlamak için uçtan uca yönergeler.
- [`license.md`](./license.md): Offline lisans isteme, doğrulama, yükleme ve denetleme akışı.
- [`policies/`](./policies/README.md): Örnek politika JSON dosyaları ve kabul kriterleri.

OpenAPI dosyası Fastify uygulamasındaki gerçek uç noktalarla senkron tutulmalıdır; yeni özellikler eklendiğinde hem şema hem de ek kılavuzlar güncellenecektir.
